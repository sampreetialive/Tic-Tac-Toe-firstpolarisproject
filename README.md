# Tic-Tac-Toe-firstpolarisproject
Tic-Tac-Toe is a classic two-player strategy game played on a 3×3 grid. Players take turns marking X or O, aiming to place three of their symbols in a row, column, or diagonal before their opponent. It's simple to learn, quick to play, and encourages logical thinking and planning.


-> ✨ This game has been built using HTML, CSS, and JavaScript. This project combines a classic game with a polished user interface, smooth animations, sound effects, and responsive design to provide an engaging experience across desktop and mobile devices.

-> ✨ Features
🎨 Modern neon-inspired UI
🌈 Smooth animations and hover effects
🎵 Sound effects for moves, wins, and draws
🎉 Confetti celebration on victory
📈 Live scoreboard for both players and draws
🏆 Animated winning line
📱 Responsive design for different screen sizes
🔄 Restart game without resetting the scoreboard

-> ✨ Built With
HTML5 – Structure
CSS3 – Styling, animations, and responsive design
JavaScript (ES6) – Game logic and interactivity

-> ✨ How to Play
Player X starts the game.
Players take turns placing X and O on the board.
The first player to get three symbols in a row (horizontal, vertical, or diagonal) wins.
If all nine cells are filled without a winner, the game ends in a draw.
Click New Game to start another round while keeping the scoreboard.
